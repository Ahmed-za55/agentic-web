# Agentic Websites

These sites already follow the Open Agentic Web principles.
Use them as examples or starting points, connect your agents, and help grow the list.

| URL | Name | Description | DevPost Team | Agent URL |
|---|---|---|---|---|
|https://worldwideagenticweb.org/|The Open Agentic Web Challenge| Answers questions about the Open Agentic Web and how to participate in the challenge.| - | [Link](https://worldwideagenticweb.org/wp-content/plugins/wwaw-agent-widget/assets/worldwide_agentic_web_widget/v1.0.9/worldwide_agentic_web_widget.network.json) |
|https://shutdown-clerk.pages.dev/|Shutdown Clerk| Answers what breaks in a public GitHub repository before a vendor shutdown or breaking release, with file:line evidence and fix steps. Runs a small model in the visitor's browser; callable by peers.| - | [Link](https://shutdown-clerk.pages.dev/shutdown_clerk.network.json) |
|https://sainath998.github.io/plainly-agent/|Plainly (agentic edition)| Explains bank letters, bills, rental agreements and lab reports in plain words. Agents only ever see a redacted copy, and run on Gemini Nano in the visitor's browser (no key).| Sainath | [Link](https://sainath998.github.io/plainly-agent/plainly_document_helper.network.json) |
|https://montbaga.github.io/agent-customs/|Agent Customs| Checks another site's AI agents for hidden tricks before they run in your browser, and adds the same check to any agentic site with one folder and two lines.| Monty Bagati | [Link](https://montbaga.github.io/agent-customs/agent_customs.network.json) |
